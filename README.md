# Med-Gemma Impact Challenge Project

This project demonstrates the use of Google's MedGemma model for healthcare applications. It includes a Jupyter notebook with code to load, fine-tune, and deploy the model for medical question answering.

## Installation

1. Clone or download the project.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the notebook: `jupyter notebook med_gemma_demo.ipynb`

## Usage

Follow the notebook cells to install libraries, load the model, prepare data, fine-tune, evaluate, and run the demo.
